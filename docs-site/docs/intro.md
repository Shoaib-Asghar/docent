# Welcome

StuzaSoft is a software development studio built by a founding team of engineers, covering the full delivery lifecycle — not just writing code, but testing it, deploying it, and keeping it running.

## What makes us different

Most small development shops hand off code and consider the job done. We treat QA and deployment as core deliverables, not afterthoughts: every project we ship includes automated tests and a working CI/CD pipeline, not a promise to "add that later."

## Who we work with

- **Local and international small businesses** digitizing a manual process — bookings, inventory, ordering, customer support
- **Local software houses** needing overflow capacity for development, QA automation, or DevOps setup
- **Startups and small teams** on Upwork and Fiverr who need a full-stack build, an automated test suite, or an AI feature integrated into an existing product
