# QA & Test Automation

This is one of our core differentiators — most development shops treat testing as optional; we treat it as a deliverable.

## What we do

- **Manual test cycles** — structured test plans covering critical user flows before any release
- **Automated regression suites** — built with Playwright or Cypress, so a change in one part of the app can't silently break another
- **Test coverage reporting** — a visible, trackable coverage percentage, not a vague assurance that "it's been tested"

## Who this is for

- Software houses needing overflow QA capacity on an existing codebase
- Founders who've been burned by a freelancer who shipped untested code
- Any team wanting to move faster without breaking things as they scale
