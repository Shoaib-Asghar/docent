# Workflow & Business Process Automation

## Tools we use

We build primarily on **n8n**, which we can self-host for clients who want data ownership and predictable costs instead of per-operation billing. We also work in **Make** for clients who specifically request it or need simpler SaaS-to-SaaS automations.

## What we typically automate

- Auto-generating invoices and notifications when a project milestone is completed
- Syncing data between a CRM, a spreadsheet, and a messaging channel
- Scheduled reports and alerts (e.g. low-stock notifications)

## Typical pricing

- Single-workflow automation: **$100–$300**
- Multi-step automation with error handling: **$300–$600**
- Ongoing automation maintenance retainer: **$1,000–$3,000/month**, depending on scope
