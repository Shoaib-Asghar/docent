# AI Integration & Chatbots

We build AI features that are wired into a business's actual data and workflows — not a generic chatbot wrapper.

## What we build

- **RAG-based assistants** — chatbots that answer questions from a business's own documentation, FAQ, or product catalog, with every answer citing its source
- **LLM integration** — wiring OpenAI or Anthropic's Claude API into an existing product or internal workflow
- **AI agents** — multi-step automated workflows, such as an agent that reads incoming messages, checks a knowledge base, and drafts or sends a response
- **WhatsApp AI assistants** — automated order-taking and FAQ handling for businesses currently replying to customers manually

## Our engineering standard

Every AI feature we ship includes an automated evaluation suite — a maintained set of test questions scored against defined accuracy thresholds — so answer quality is measured before and after every change, not assumed. This is the same discipline we apply to regular code, applied to AI outputs.
