# Web Application Development

We build custom web applications end to end — frontend, backend, testing, and deployment — rather than handing off untested code.

## Our stack

- **UI/UX:** designed in Figma, using a shared component system for consistency across projects
- **Frontend:** React, with Next.js for anything needing server-side rendering or SEO
- **Backend:** Node.js (Express/NestJS) as our primary backend, with Python (Django/FastAPI) for anything data- or AI-heavy
- **Testing:** Playwright for end-to-end tests, Jest/Vitest for unit tests — every project ships with automated test coverage, not manual spot-checks
- **Deployment:** Docker containers, GitHub Actions CI/CD, deployed to a cost-appropriate host — a VPS for smaller projects, AWS/GCP when a client needs scale or compliance

## What we typically build

- Booking and appointment systems with automated reminders
- Internal business tools — inventory tracking, order management, simple CRM-style dashboards
- Customer-facing web apps with authentication, payments, and admin panels
