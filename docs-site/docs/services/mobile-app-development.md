# Mobile App Development

## In-house: Flutter

We build cross-platform mobile apps in Flutter as our primary in-house stack — one codebase covering both iOS and Android, using the same design system as our web projects for visual consistency.

## Specialist stacks: by arrangement

For projects that specifically require native Android (Kotlin), React Native, or Kotlin Multiplatform — usually because of an existing legacy codebase or platform-specific hardware access — we bring in a vetted specialist under our own project management and QA sign-off, so the delivery standard stays the same regardless of who writes the code.

## What we typically build

- Loyalty and ordering apps for retail and food & beverage businesses
- Booking companion apps paired with a web dashboard
- Internal field apps for businesses managing distributed staff or inventory
